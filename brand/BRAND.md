## Brand asset files

All files in the folder `brand/`: the logo in all versions (`logo/` – mark, lockup and loading still images), the
app icons (`icon.ico`, `icon.png`) and the logo card of the loading animation (`loadcard.json` – its corner, fold and
tilt), and this file.

## Without this folder

The code that shows these assets (`qml/components/Lockup.qml`, the loading shader, the launcher's `DrawLoadCard`,
`ui/iconkit.py`) is licensed under the GPL. Without the `brand/` folder the program builds and runs with neutral
placeholders: a plain grey card instead of the mark, the name as text, and a random first loading card.
